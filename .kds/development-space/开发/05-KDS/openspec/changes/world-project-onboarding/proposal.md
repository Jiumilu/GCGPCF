## Why

用户要求 World 纳入项目群并建立本地 Git 与远端；当前无独立仓库或项目登记。

## What Changes

新增 World 工程与治理基线、项目清单/技能链/适用性矩阵登记；在 Feature 项目白名单增加 world；将覆盖验证器的固定项目总数由21更新为22。

## Capabilities

### New Capabilities
- `world-project-registration`: World 独立纳管与可核验 Git 基线。

### Modified Capabilities
无。

## Impact

仅 World 新仓、GPCF 纳管入口及两处必要校验配置代码、协同/Harness 技能登记。F-021 为执行记录。用户已授权本次范围；不修复无关历史门禁、不迁移 Studio 或 KDS。
