# F-012 ICP→SOP 单向强依赖实施计划

## 1. 目标

SOP 矩阵消费**版本化** ICP 规则/产业模型/场景模板/约束清单，不复制、不弱化；ICP 基线升级时 SOP 可检测不兼容并恢复。

## 2. 里程碑

| 里程碑 | 内容 | 验收 |
|---|---|---|
| M1 契约 | 定义 ICP→SOP 引用清单（版本号 + 端点 + 字段） | 清单评审通过 |
| M2 读取 | SOP 启动时校验 ICP 版本与必填字段 | 缺版本/不兼容时拒绝并给出恢复提示 |
| M3 消费 | SOP 矩阵直接引用 ICP 的 24 节点/11 资源池/3 场景/5 角色 | 无复制数据；字段映射可回放 |
| M4 门禁 | SOP tests + 版本兼容 validator 入 CI | 变更时自动检测 |

## 3. 验证

- ICP 侧：`gc_icp.api` 5 GET 200（F-019 已验）。
- SOP 侧：SOP 专属测试命令 + 版本兼容 validator（待 SOP 属主提供）。
- 禁止：复制 ICP 数据到 SOP 仓作为事实源。

## 4. 风险

- SOP 当前 iteration 0，无实现；需 SOP 属主排期。
- ICP API 未做正式版本兼容承诺；需先冻结版本字段。

## 5. 非声明

- 不声明已实现；不声明 F-012 可关闭。
