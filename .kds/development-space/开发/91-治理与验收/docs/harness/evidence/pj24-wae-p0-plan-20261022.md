## 3. P0 四项实施计划

### O1 外壳解耦

- **目标**：纯框架壳可独立运行；WAME 专属能力（FunctionPanel / RightAIAssistantPanel / WASM / 性能监控 / 项目持久化）全部以能力开关（默认关）或槽位注入，不在壳内硬编码。
- **scope.in**：`ShellProps` 契约冻结（slots + capabilities + 默认值语义）；`describeShellComposition()` 自检可机器判定"壳是否干净"；WAME 整块直出应用在能力全关下的回归基线；壳层 E2E（独立入口不传参时无右侧面板、默认动作区不变）。
- **scope.out**：不实现 WAME 专属插件内部行为；不做注册表驱动的 `activeAppId`/`mountMode`（设计 §3.3 草案，属后续步骤）；不改母本仓。
- **依赖**：唯一总体方案确认；WAE Feature 载体与专属 tests/build 命令；WAME 全量测试基线可复跑。
- **验收标准**（全部可机器/可回放）：① `shellCapabilities.test.ts` 9 例 pass（默认全关、`aiPanel≡slots.rightPanel`、`describeShellComposition()` 空入参 `isCleanFrameworkShell=true`）；② 独立运行入口 E2E：无右侧面板、顶栏默认动作区不变；③ WAME 侧能力全关时 tsc + vitest 全绿；④ G1/G4/G5/G8/G9 门禁记录入 Feature evidence。
- **风险**：壳内能力耦合导致抽取反复；WAME 回归。缓解：先列依赖清单逐项判定"下沉/插件化/剔除"；抽取前后跑 WAME 全量测试。
- **回滚**：能力开关默认全关即恢复母本行为；壳件为最小改造件，`BASELINE.md` 直出清单可逐件回退；不涉及后端/数据/环境。

### O2 令牌收口

- **目标**：项目群单一 `ui-tokens` 来源；各项目引用同一份令牌；视觉等价可证明（逐字节/别名关系，而非"看起来没变"）。
- **scope.in**：`tokens.css` 单一来源与 `TOKEN_NAMES` 一致性；`semantic.css` 只新增别名、不覆盖基础令牌；迁移期双命名；PKC 4 处、Brain 30 处+5 独有令牌的偏离裁定输入；接入项目替换复制件的 T2 最终形态。
- **scope.out**：不擅自对齐 PKC/Brain 的偏离值（需项目 owner/老卢裁定）；不清理对方项目 `globals.css`（Brain 0 字节空文件、PVAOS 68KB 业务样式混入令牌层——仅记录）。
- **依赖**：目标项目修改授权（改对方仓）；偏离裁定；O1 壳件已引用单源。
- **验收标准**：① `tokens.test.ts` 8 例 pass（集合一致、`default_theme.css` 不再声明令牌、`--color-* ↔ --*` 34 对、语义别名无悬空）；② `tools/verify-token-sources.py` exit 0，复制件逐字节相同；③ 接入项目 import 单源后 tsc/vitest pass + ≥3 页视觉零回归（像素比对在目标项目侧执行）；④ 偏离项有裁定记录（不得静默）。
- **风险**：视觉分裂；Tailwind `@theme inline` 令牌运行时不可读导致断言写错（V6 已记录，改用读 CSS 源单测）；双命名长期并存。缓解：迁移期双命名 + 等价证明 + 逐项目裁定。
- **回滚**：复制件在 B4 收敛前保留；接入项目将 import 退回本地复制件即恢复；新增语义层为纯别名，删除不影响既有外观。

### O3 侧栏统一

- **目标**：框架内只保留一套导航侧栏；WAME 的 `FunctionPanel` 以插件/槽位形态存在而非第二套侧栏；接入项目按批次归并。
- **scope.in**：框架侧唯一侧栏（已完成，待复跑归档）；应用切换器全页唯一（`toHaveCount(1)`）；WAME 作为首个 A 档应用时的 `FunctionPanel` 插件化与回归；B2/B3/B4 各批次的侧栏归并判据。
- **scope.out**：不在本计划中改 WAME/PKC/Brain/PVAOS 任一仓；不做"全部项目一次性归并"；不把业务面板当成导航侧栏强行合并。
- **依赖**：O1 能力/槽位契约；目标项目代码授权与测试基线；WAME 作为母本先验证。
- **验收标准**：① 框架独立入口 + WAME 整块直出应用均"全页只有 1 个应用切换器/导航侧栏"（E2E 断言）；② WAME `FunctionPanel` 经槽位注入后 WAME 全量测试通过且无第二侧栏；③ 各接入批次按 §4 判据；④ 例外（确需独立侧栏）走三方审批并登记。
- **风险**：`FunctionPanel` 1557 行迁移面大；侧栏职责（业务面板 vs 全局导航）混淆；母本回归。缓解：先 WAME 单点验证；能力默认全关；例外机制兜底。
- **回滚**：关闭对应 capability 即恢复母本侧栏；未合并前保留原侧栏，不影响目标项目运行。

### O4 状态语义层

- **目标**：项目群统一 7 值状态字典（running/blocked/partial/review/complete/candidate/human_required），"未映射不得进入统一外壳"、"GCPF 门禁词不得折算 complete"为代码级判定。
- **scope.in**：字典与中文标签；语义令牌（主色 + subtle，全为别名）；`StatusBadge`；S1/S2 判定与测试；接入项目状态词映射表补全（纳入时）。
- **scope.out**：不把 `accepted/integrated/production_ready/customer_accepted` 纳入字典；不做 AI 产出溯源（S3，当前无该类组件）；不替代各项目自身业务状态。
- **依赖**：无外部强依赖；映射扩展需各项目状态词清单（随纳入采集）。
- **验收标准**：① `statusDictionary.test.ts` 11 例 pass（7 值稳定、每值有标签与两令牌、未知词→`unmapped` 且 `canEnterUnifiedShell()=false`、6 个门禁词→`gcpc_gate` 不折算）；② `semantic.css` 全为别名且无悬空引用；③ 接入项目映射后 0 个 `unmapped` 混入外壳；④ E2E：未映射词显式标注、门禁词显式标注。
- **风险**：错误折算造成"假完成"（已由 S2 代码锁死）；各项目词表遗漏。缓解：映射表值域限定 7 值（测试锁死）；纳入时逐项目核对。
- **回滚**：字典/令牌/StatusBadge 均为框架新增件（非母本直出），撤回使用点即可，不影响母本；语义令牌为新增别名，不覆盖既有。
