# XAP 统一治理交换协议 · Codex 提案采纳意见 v0.1

- 日期：2026-10-11 ｜ 性质：**提交侧（WAS/XWAIL）对《Codex 综合分析提案》的逐项采纳意见**——决策权属治理方（老卢）；本件不代拍板
- 提案原文要点见本件 §一 对照表（来源：Codex 综合分析，2026-10-11，`authorization=analysis_and_proposal`）

## 〇、总评

**方向采纳（全向认同）**：将 XAP 确立为「项目群各系统与 WAME 之间的**统一治理交换协议与包格式**」——与既有《WAME统一审核请求机制》同向，Codex 提案为**精确化与补全**。本件把提案拆为三类处置：**采纳／调整采纳／待拍板**，并附 **P0 收口清单**。

**最重要的转向确认**：**从「提交侧增加样例」转向「协议收口 ＋ 受理侧闭环」**——我方提交侧样例生产线**就此停线**（5 包/4 请求/工具链已足），后续动作按 P0 收口清单执行。

## 一、逐项对照与采纳意见

| 提案要点 | 体系现状（出处） | 采纳意见 |
|---|---|---|
| 协议三层：协议／包／接入接口；离线导入同走服务端校验 | 机制 §二（两类包）＋《接入点》8 接口 | **采纳**；首期 HTTP＋状态查询——采纳 |
| 两类主体包（asset／request）＋两类配套消息（Receipt／Execution Report） | 机制有回执**概念**（receipt 字段）；**未成 Schema** | **采纳**；Receipt／Execution Report 规格＝**P0 首期交付物**（提交侧先出草案，正式 Schema 归 XWAIL） |
| 双向桥（提交／受理／查询／回传） | 机制 §三 受理流程 | **采纳** |
| 决策三义分离：`requestedDecision`／`compatibilityDecision`／回执 `decision` | 留白纪律（R06 v2）；manifest `decision`=兼容性（XAP-1003） | **采纳**；"既有 `decision` 字段版本化迁移消除歧义"——归 XWAIL 正式迁移；提交侧在回执规格草案中**先行区分** |
| 协议最小核心 8 项（protocolVersion／幂等键／身份核对／证据稳定引用…） | 信封 10 必填含子集 | **采纳**；补充项（`protocolVersion`／幂等键／有效期）纳入回执规格草案＋requestcheck 后续演进 |
| 四约束：版本分离／不可静默替换／幂等／**声明非权限** | R06（留白）＋版本实践部分在案 | **采纳**（四约束全收）；"声明非权限"与「不得越权声称」一脉 |
| 四级检验**按类型适用**：导入检查≠术语检查；证据**不可访问→待补证/阻断** | R08 已做**包级分流**；**模式级未按类型**；R07 已做格式+存在性 | **调整采纳**：①模式级（V1.2-06）限定导入类请求 ②"不可访问→待补证"属**受理侧状态语义**（提交侧只判格式/存在——状态流转归 WAME 受理器） |
| WAME 受理内核 9 能力（接收/校验/台账/分流/工作台/回执/发布控制/反馈/恢复） | S4（未实现，其流程） | **采纳**为 WAME 实现建议（归其立项） |
| 三线状态分离（请求处理／资产治理／运行执行） | 治理面/运行面**两线**已在案；**请求处理线=新** | **采纳**（三线全收；请求处理线状态机：已接收→校验中→待补证/待审核→已裁定→已归档） |
| 职责分配表（含 **MMC 可信身份**） | 语义契约固定关系（WAS/Ontology/XWAIL/WAME/AaaS） | **采纳**；MMC 身份角色待其项目确认（M13 登记值） |
| P0-P4 实施路线＋验收门槛 | S1-S4（**子集**） | **采纳为基准路线**；S 系列映射：S1≈P0（部分已完成）／S2≈P0-P1 间／S3＝P3 预置／S4＝P1-P2 的受理器部分 |
| 6 级完成度统计（可构包/受理/裁定/回执/执行对账/已验收） | 无（新） | **采纳**——替代"包数量"口径 |
| 两条首批链：轻量请求链（KDS/CWME→WAME→回执）＋资产交付链（XWAIL→WAME→PVAOS→执行报告） | — | **采纳**（首批范围建议） |
| 边界：**WAME 非业务流量中转站**（内部处理/实时控制/普通查询走原接口） | 无明文 | **采纳**（本件固化为边界条款） |
| XL/T4 工作量；跨项目契约收口归 GC 治理会话；实现拆单仓任务 | 与我方"契约收口归 GPCF、实现归各仓"一致 | **采纳** |
