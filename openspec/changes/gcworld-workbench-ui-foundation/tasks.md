## 1. 产品授权与基线

当前执行说明：旧宽范围任务不以部分实现自动勾选。2026-09-05人工长期目标授权的本地业务切片见第6节；产品实现已落在Studio/F-015，新增真实数据、权限与生产动作仍另行授权。

- [ ] 1.1 批准所属Release、后继Feature、产品仓库、产品与设计责任人、线程和有界文件范围。
- [ ] 1.2 确认首批用户角色、四中心纵向切片、屏幕范围、中文规范、可访问性等级和验收环境。
- [ ] 1.3 批准固定契约数据、只读视图接口、租户范围、脱敏规则、凭据和功能开关。
- [x] 1.4 复核现有设计系统、组件库和路由架构，记录复用边界而不另建重复体系。

## 2. 测试先行的界面基础

- [ ] 2.1 为跨中心资产、项目、快照和权限上下文保持编写失败测试。
- [ ] 2.2 为事实、运行、目标、模拟、候选、冲突和受限状态的中文及非颜色表达编写视觉语义测试。
- [ ] 2.3 为字段、图、搜索、统计、导出和智能体回答的一致裁剪编写负向泄漏测试。
- [ ] 2.4 为只读阶段的动作禁用、草稿边界和缺失授权提示编写交互测试。

## 3. 四中心纵向切片

- [ ] 3.1 实现统一应用外壳、十二中心导航、面包屑和世界上下文切换。
- [ ] 3.2 实现世界总览、组织资产、关系网络、项目世界及单一资产档案的固定数据版本。
- [ ] 3.3 实现证据、有效时间、冲突、可信等级、模拟假设和裁决依据的解释入口。
- [ ] 3.4 完成键盘导航、焦点、对比度、缩放、响应式和中文长文本验证。

## 4. 只读数据与权限集成

- [ ] 4.1 获得数据集成独立授权后，接入经批准的只读GCWORLD视图接口并固定契约版本。
- [ ] 4.2 验证服务端裁剪先于界面呈现，客户端隐藏不会替代权限控制。
- [ ] 4.3 验证搜索、统计、导出和跨中心跳转不会泄漏受限实体、边或数量。
- [x] 4.4 保持跨租户共享和所有真实动作关闭，直至各自获得单独授权与运行时回执能力。

## 5. 验证、证据与回滚

- [ ] 5.1 执行单元、组件、构建、格式、类型、可访问性、响应式和浏览器端到端检查。
- [x] 5.2 验证GKE‑001 Program与CodeGraph绑定；只有真实消费关系变化时才更新权威映射。
- [ ] 5.3 更新Feature日志、Evidence Index、验收矩阵和中文文档，并通过OpenSpec严格校验及项目群文档门禁。
- [ ] 5.4 演练关闭功能开关、移除路由和回退只读视图契约，不修改世界事实或业务系统。
- [ ] 5.5 将结构、固定原型、只读集成、权限集成和真实运行证据分级提交Harness独立复核。

## 6. 开发优先的本地业务迭代

- [x] 6.1 项目行动总览：在28项登记上实现行动有无、负责人组合筛选及刷新、详情返回保持，验证18项有行动与10项无可验证行动。（Studio LR-922，本地验证，不代表真实执行）
- [x] 6.2 历史追踪：仅消费现有快照时间与会议引用，区分更新、截止及未知时间；验证不伪造事件、进度或当前逾期。（Studio LR-923，本地登记时间线，不代表完整业务历史）
- [x] 6.3 本地辅助：以绑定项目与来源生成整理建议及草稿，具备异常反馈，验证不调用真实连接器、不写KDS、不自动认定事实。（Studio LR-924，本地规则整理，不代表模型能力或真实执行）
- [x] 6.4 版本化快照适配：在不可变源数据之外校验版本和来源、区分世界类型与候选确认状态；以既有快照及隔离测试数据验证不匹配版本、状态串用和可重建投影。（Studio LR-925；来源元数据绑定，不是内容权威或浏览器原始字节认证）
- [x] 6.5 快照增量比较：按稳定标识比较新增、修改、缺失与来源版本，提供变化查看与返回；仅使用既有快照及隔离测试版本，不按名称合并身份，不宣称真实KDS增量接入。（Studio LR-926，唯一真实版本自身比较与隔离版本验证，原草稿保留）
- [x] 6.6 资产清单与详情的键盘、焦点及移动端阅读：查找候选后打开详情、查看来源并返回清单保持定位，验证只读且不扩大数据范围。（Studio LR-927；22条浏览器流程通过，不代表全应用无障碍验收）
- [x] 6.7 本地行动反馈草稿：在既有项目及来源绑定下记录人工核对备注，支持保存恢复、项目隔离及撤销；不将备注当真实执行结果，不修改历史项目状态或写KDS。（Studio LR-928；双类草稿隔离及26条浏览器流程通过，标签页本地能力）
- [x] 6.8 候选关系逐项解释与返回：区分证据计数连接、同名候选与实际业务关系，允许查看已有依据及缺失内容、定位同名候选后返回；仅用现有授权快照。缺少真实关系依据时保留首阶段验收缺口，不以界面展示替代数据授权或事实确认。（Studio LR-929；29条浏览器流程通过，同名跳转仅由隔离分组验证）
- [x] 6.9 项目层级关系浏览：利用28项项目已有父子标识展示历史登记关系，支持节点定位、项目详情与来源查看、返回原层级；不按名称推断组织项目绑定，不将历史登记提升为当前正式事实。（Studio LR-930；2条双向历史登记连接，32条浏览器流程、2887项单元回归及构建通过，仅本地验证）
- [x] 6.10 首阶段任务连贯性与移动入口：核对资产查找、项目行动、层级、历史与辅助的完整用户任务，优先减少长距离滚动和上下文丢失；复用现有视图，不新增空工作中心，不把真实关系数据缺口包装成完成。（Studio LR-931；五个任务直达入口、34条浏览器流程、2887项单元回归及构建通过，保留真实关系与多用户缺口）
- [x] 6.11 本地草稿工作入口：在现有项目行动总览查找当前标签页已保存的待办与核对反馈，定位项目继续处理；仅使用已有项目标识和本地存储，明确损坏、版本不符及清除状态，不冒充真实任务或跨用户协作。（Studio LR-932；37条浏览器流程、2891项单元回归及构建通过，包含重复进入和未保存保护）
- [x] 6.12 首阶段业务验收核对：已按资产项目查找、来源关系、行动历史及本地辅助列明实现与缺口，明确最小真实试点数据和接口授权。发现快照进入公开静态产物的交付风险，后续优先安全读取；本勾选仅代表核对完成，不代表首阶段验收通过。（见F-015既有摘要，未递增产品迭代）
- [x] 6.13 安全快照读取闭环：已将两份快照迁至服务端私有目录，默认无授权、精确范围读取、短期续验、拒绝重试和退出清除；43条浏览器流程、2925项全仓测试及构建通过，本地真实路由使用隔离身份验证固定数据。未授予真实权限、未连接真实KDS/MMC或用户库，未更新生产旧构建。（Studio LR-933；仅本地交付，不代表正式权限集成）
- [ ] 6.14 单项目关系依据闭环：先在隔离契约和既有界面中实现端点、关系类型、来源定位、有效时间与确认状态；具名真实关系数据获准后再完成实际追溯验收。不得从相关方名称推断身份或关系，不以测试夹具替代真实闭环完成。

  - [x] 6.14.2 人员—组织—项目候选关系本地契约：可选关系包校验、明确或未决端点、逐条来源与有效日期、无效包隔离、候选档案刷新返回及移动草稿保护；Studio LR-935，49条浏览器、2954项单元及构建通过，仅为隔离测试验证，未增加真实关系。
