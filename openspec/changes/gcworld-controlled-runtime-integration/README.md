| 文档 | 用途 |
| --- | --- |
| `proposal.md` | 运行目标、能力和边界 |
| `design.md` | 服务协作、裁决、回执与故障降级设计 |
| `tasks.md` | 获得独立授权后方可执行的任务清单 |
| `specs/` | 可验证的受控运行行为要求 |
