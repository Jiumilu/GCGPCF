# 场景流扩展登记草案（WAS 流集合·候选扩展）

> 状态：draft（candidate）｜提出：2026-10-16｜依据：老卢 2026-10-16 裁定、GCWORLD 总体架构 V1.0.1（KDS）、WAS 总体方案 v1.3.0 U16
> 本件为登记草案，不构成契约变更；正式纳入须经 WAS 治理复核并走版本化发布。

## 1. 扩展对象

- 名称：场景流 ｜ 英文：`ScenarioFlow`
- 英文命名对齐：与体系既有「场景 = Scenario」词根一致（场景资产包、Scenario Instance Model 等同词根）。
- 状态：candidate（候选扩展）｜ 迁移决定：compatible

## 2. 定义（单源照录）

- 裁定原文（2026-10-16）：「维度+上下文就是谁在什么情景下的变化。就定义为场景流吧」。
- 定义：**主体在特定情景（时点、区位、场景）中的变化与迁移。**
- 运行要素：主体 ｜ 情景（时点·区位·场景）｜ 轨迹 ｜ 状态切换 ｜ 迁移记录。

## 3. 与既有体系的关系

- **与八流**：作为流集合的新成员（GCWORLD 语境称第九流）；不替代、不改名、不合并任何既有流。
- **与 SpaceTimeDimension（时空维）**：维度侧不变（位置、坐标系、时间窗口、轨迹、有效期与历史状态）；场景流为运行层对「主体-情景-变化」的流式表达，与时空维构成「表达层 vs 维度层」的关系。
- **与四世界隔离**：默认归属现实世界记录；推演/模拟场景中的场景流遵循 `worldLayer` 标注规则。
- **与 GCWORLD**：GCWORLD V1.0.1 九流表为当前引用源；本扩展正式纳入后由其回填注记。
