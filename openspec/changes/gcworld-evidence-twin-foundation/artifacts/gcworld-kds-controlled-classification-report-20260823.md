# GCWORLD KDS全量受控分级与组织资产候选覆盖评估报告

## 一、结论

本轮已对经用户“全量允许”确认的一次性隔离快照完成全来源受控分级和组织资产候选提取。42,971个可发现来源全部进入明确处置台账，来源处置覆盖率为100%；扫描前后来源文件修改数为0，KDS、MMC和业务系统写入数均为0。

本轮得到的人员、组织和关系均为“未决候选”，不是已归一化世界资产。当前已归一身份数为0，身份归一完成率为0%。因此本报告状态为 `partial / rework`，不得据此宣称“没有遗漏任何人或组织”、已完成世界初始化、已集成或生产就绪。

## 五、关系证据覆盖

本轮生成93,570条关系证据候选，覆盖“来源提及”和“承担候选职能”等关系。校验结果如下：

- 关系候选标识全部唯一；
- 每条关系的主体候选均存在；
- 每个候选登记的关系证据引用均可解析；
- 所有关系状态均为未决候选，没有写入事实世界；
- 没有从模拟状态或目标状态直接提升为事实关系。

## 八、剩余工作与准入条件

1. 按来源证据对11,326个不同显示名称开展身份归一，先处理高频、跨项目和高业务影响候选。
2. 对17,338个S3/例外项逐类复核；未经独立授权不得扩展内容读取范围。
3. 建立人物、法人组织、非法人团队、政府机构和项目组织的权威锚点规则。
4. 对候选提取结果进行分层抽样，形成准确率、召回风险和规则修订证据。
5. 只有人工确认、证据充分且通过WAES门禁的候选，才可提出事实世界提升申请；本轮授权不包含写入或提升。

当前结论保持：来源层全量处置已完成，组织资产身份层和事实世界初始化尚未完成。
