# GCWORLD第一批临时责任路由模型批准回执

## 一、人工决定

老卢于2026年8月28日明确批准第一批身份复核采用临时责任路由模型：

1. GKE‑001承担人员、法人、政府机构及跨域冲突候选的机器归一、证据整理和初步责任路由；
2. 项目组织由对应项目PMO或项目负责人承担主复核；
3. 非法人团队及社会组织由对应发起组织治理负责人承担主复核；
4. 涉及真实业务确认时，动态路由至人事、法务、商务、政府关系、合规或项目责任人；
5. F‑013独立复核线程承担第二复核；
6. 老卢仅承担重大争议和最终人工裁决。

人工决定同时明确：不授权自动身份合并、正式世界资产生成、KDS写入、事实提升或权限授予；未找到可验证业务责任人的复核项继续保持未决，不启动SLA。

## 五、下一执行边界

下一节点可在不读取实时KDS或来源正文的前提下，对九百七十三项执行GKE‑001机器归一准备：整理候选引用、证据引用、名称冲突和责任路由建议。该节点只能生成建议与例外，不得自动合并、生成正式世界资产、调用KDS写接口、事实提升或权限授予。

四十三项项目组织和非法人团队候选在真实PMO、项目负责人或发起组织治理负责人被验证并接受前，继续保持待分派。所有SLA保持未启动。
