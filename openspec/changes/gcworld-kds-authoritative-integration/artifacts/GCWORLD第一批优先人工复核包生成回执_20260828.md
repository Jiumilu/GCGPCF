# GCWORLD第一批优先人工复核包生成回执

## 一、生成结果

本节点已经将第一批机器归一例外中的五项多类型冲突和十五个同名候选组整理为二十个独立人工复核包，共覆盖三十五个互不重叠的复核项。

| 复核包类型 | 复核包 | 复核项 | 优先级 |
| --- | ---: | ---: | --- |
| 多类型冲突 | 5个 | 5项 | 一级 |
| 同名候选组 | 15个 | 30项 | 二级 |
| 合计 | 20个 | 35项 | — |

多类型冲突与同名候选范围没有重叠。每个同名候选组包含两个独立复核项；即使显示名称的比较值相同，也继续保留各自复核项标识、候选引用、来源证据引用和关系证据引用。

## 二、复核包内容

每个复核包均包含：

1. 独立且确定性的复核包标识；
2. 复核项、机器建议、例外代码和证据包建议；
3. 主复核责任角色建议、F‑013第二复核和重大争议升级边界；
4. 真实责任主体需要提交的授权、范围、有效期、受众、敏感边界及利益冲突声明字段；
5. 未发送、未接受、未启动SLA和不得直接产生正式结果的状态控制；
6. KDS提交、仓库树及工作树只读指纹。

复核包允许责任主体提交建议结论，但任何建议都不能直接成为正式身份决定，仍须经过独立第二复核和适用的人工裁决门禁。
