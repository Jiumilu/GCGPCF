## 二、权威锚点要求

所有需求包均要求责任主体声明下列共同字段：责任组织资产标识、权威角色、授权依据、可验证线程或身份、责任范围、有效起始时间、有效截止时间、目标受众、业务敏感边界、分发约束、撤销或到期条件、利益冲突声明及当前接受人。

各类候选还必须补齐专属权威锚点：

| 主体类型 | 专属权威锚点 |
| --- | --- |
| 政府或公共机构 | 正式机构全称、行政层级与地域管辖、机构编制或权威登记标识、具体部门及职能边界、关系有效期间 |
| 自然人 | 经授权的唯一人员标识、所属组织与岗位、项目或业务关系、任职及关系有效期间、同名与别名排除证据 |
| 法人或市场主体 | 法定登记全称、统一社会信用代码或等价登记标识、登记状态与有效期间、集团或分支边界、法务或商务责任确认 |
| 其他组织 | 正式名称、发起或主管组织、章程或成立依据、成员与治理边界、存续及关系有效期间 |

任一字段缺失、授权依据不可验证、存在责任冲突或主体拒绝接受时，对应复核项继续保持未决且不启动SLA。
