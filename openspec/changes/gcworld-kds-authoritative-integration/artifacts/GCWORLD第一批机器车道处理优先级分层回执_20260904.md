## 一、执行结果

第一批九百三十八项机器证据压缩车道记录已完成高、中、低三级处理顺序划分。分层结果只决定机器整理与责任路由准备的先后顺序，不表示身份可信度、事实有效性或合并许可。

| 处理优先级 | 数量 | 当前动作 |
| --- | ---: | --- |
| 高 | 221项 | 优先整理权威锚点需求与责任路由材料 |
| 中 | 536项 | 在高优先级批次之后处理 |
| 低 | 181项 | 保持队列，不因低优先级降低治理要求 |
| 合计 | 938项 | 全量覆盖且每项唯一归层 |

## 二、可解释分层规则

每项处理评分等于“证据规模分”与“主体治理敏感度分”之和。所有阈值和权重均写入逐项清单，不使用隐藏模型评分。

证据规模取候选、来源和关系三类证据数量的最大值。本批次候选证据中位数为18条，上四分位为32条；关系证据中位数为18条，上四分位为36条；两类证据前十分位均约为90条。为保持单一、审慎且容易复算的边界，统一采用18、36和90三个阈值。

| 最大证据数量 | 证据规模分 |
| --- | ---: |
| 不少于90条 | 3分 |
| 36至89条 | 2分 |
| 18至35条 | 1分 |
| 少于18条 | 0分 |

| 主体类型建议 | 主体治理敏感度分 | 原因 |
| --- | ---: | --- |
| 政府或公共机构候选 | 3分 | 公共机构身份关系具有较高治理敏感度 |
| 自然人候选 | 2分 | 涉及个人责任与权限边界 |
| 法人或市场主体候选 | 2分 | 涉及法律与商务责任边界 |
| 其他组织候选，需人工确认 | 1分 | 先按一般组织治理敏感度排序 |

总分4分及以上为高优先级，2至3分为中优先级，0至1分为低优先级。同等证据规模和同类主体必然得到相同优先级；等级内再按评分、证据数量和原输入顺序形成稳定处理序号。
