# GCWORLD第一批人工责任分派与最低证据需求矩阵说明

## 一、结果

已为第一批一千零十六个高频身份复核项建立人工责任角色、独立第二复核、争议升级和最低证据需求矩阵。矩阵只定义复核责任和证据门槛，不代表具体责任人已经接受任务，也不包含任何身份合并、拆分、驳回或事实提升决定。

本轮仅使用既有S2类型与权威锚点建议数据，没有读取实时KDS、来源正文、S3正文或UNKNOWN正文，没有调用服务、接口或数据库。

## 二、治理依据

历史批准的身份治理模型包括：

- 老卢暂任身份、关系争议和身份归一的最终人工裁决人；
- F‑013独立复核线程承担第二复核；
- 复核时限为五个工作日；
- 超期时保持候选或例外，禁止自动合并或扩大读取；
- 争议升级至GKE‑001协调线程，原状态保持不变。

该历史授权已因仓库基线变化失效。因此本矩阵将其作为待重新确认的责任模型，而不是当前已经激活的逐项授权。五个工作日计时只有在责任角色接受且证据包完整后才能开始。

## 四、通用最低证据

每个复核项必须具备：

1. 完整候选、来源证据和关系证据引用；
2. 来源有效性、撤销状态和证据可信等级；
3. 有效时间和记录时间；
4. 别名、同名、冲突与未决事项清单；
5. 主体类型对应的正式登记、批准、任职或代表关系证据；
6. S3和UNKNOWN内容未获独立授权时保持不可读；
7. 主复核意见与F‑013独立第二复核意见；
8. 最终人工决定及其依据、有效期和撤销条件。

## 五、分类型证据重点

- 自然人：稳定人员锚点、任职或代表关系、责任主体确认、重名和有效时间核验；
- 法人或市场主体：统一社会信用代码、正式登记名称、登记机关、法人或授权代表、集团法人边界；
- 政府或公共机构：法定机构代码、正式政府目录、上下级关系、联络或代表关系；
- 项目组织：立项或批准编号、责任组织、项目负责人、成员、有效期和授权范围；
- 非法人团队或社会组织：章程或成立文件、发起组织、负责人、成员边界和存续期；
- 其他或冲突主体：先完成主体类型核验，再应用相应权威锚点和证据标准。
