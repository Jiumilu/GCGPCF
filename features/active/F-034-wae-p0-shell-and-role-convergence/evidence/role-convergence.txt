## 3. 机器可读角色矩阵（只读脚本，真实消费 MENU_CATALOG + APP_NAV_CONFIG）

命令（临时脚本在 `/tmp`，不写入仓库）：`pnpm exec tsx /tmp/verify-f034-role.mts`

脚本内容（只读；可原样复跑，与本轮实际执行的 `/tmp/verify-f034-role.mts` 逐字一致）：

```ts
import { pathToFileURL } from 'node:url';

const ROOT = '/Users/lujunxiang/Projects/GlobalCloud V0.0.1/GlobalCloud WAE';
const load = async (rel: string) => import(pathToFileURL(`${ROOT}/${rel}`).href);

const { MENU_CATALOG, menuIdsFor } = await load('packages/host-kit/src/host/menus.ts');
const { APP_NAV_CONFIG } = await load('apps/wame/src/app/apps/generated.ts');

const catalogIds = new Set(MENU_CATALOG.map((m: { id: string }) => m.id));
const entries = APP_NAV_CONFIG.entries as Array<{ id: string; app: string; requires?: string }>;
const serviceEntries = entries.filter((e) => e.app === 'service');

const unknown = entries.filter((e) => e.requires && !catalogIds.has(e.requires));
const viewerMenus = menuIdsFor({ role: 'viewer' });
const adminMenus = menuIdsFor({ role: 'system-admin' });
const unauthenticated = menuIdsFor({});

const viewerVisibleRestricted = serviceEntries.filter((e) => e.requires && viewerMenus.includes(e.requires));
const adminMissing = serviceEntries.filter((e) => e.requires && !adminMenus.includes(e.requires));
const unauthVisibleRestricted = serviceEntries.filter((e) => e.requires && unauthenticated.includes(e.requires));

console.log('catalog_menu_ids =', MENU_CATALOG.map((m: { id: string }) => m.id).join(','));
console.log('service_entries =', serviceEntries.map((e) => `${e.id}->${e.requires}`).join(', '));
console.log('requires_unknown_ids =', JSON.stringify(unknown.map((e) => e.requires)));
console.log('viewer_menus =', JSON.stringify(viewerMenus));
console.log('system_admin_menus =', JSON.stringify(adminMenus));
console.log('unauthenticated_menus =', JSON.stringify(unauthenticated));
console.log('viewer_visible_restricted =', JSON.stringify(viewerVisibleRestricted.map((e) => e.id)));
console.log('admin_missing_required =', JSON.stringify(adminMissing.map((e) => e.id)));
console.log('unauthenticated_visible_restricted =', JSON.stringify(unauthVisibleRestricted.map((e) => e.id)));
const ok = unknown.length === 0 && viewerVisibleRestricted.length === 0 && adminMissing.length === 0 && unauthVisibleRestricted.length === 0;
console.log('RESULT =', ok ? 'PASS' : 'FAIL');
process.exit(ok ? 0 : 1);
```

service_entries = gcas-console->gcas, mmc-console->mmc, gpcf-console->gpcf, icp-console->icp, aaas-console->aaas, feedback-console->feedback, idp-console->idp-console
