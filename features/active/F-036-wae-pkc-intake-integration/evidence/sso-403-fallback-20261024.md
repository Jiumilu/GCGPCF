# 401/403 可读降级实现

## 变更

WAE `apps/wame/src/app/apps/PkcIntakePage.tsx`：
- 启用受控嵌入后启动 8s 计时；
- iframe `onLoad` 成功则取消提示；
- 8s 未 load 显示可读提示：可能 401（未登录）/403（无权限）/CSP 拒绝，不静默。

## 验证

- 新增 DOM 测试：8s 未 load 显示 `pkc-embed-slow`（含 401/403 文案）。
- PkcIntakePage.dom.test.tsx：**8 passed**。
- WAE 全量：**1473 passed**。
- 构建：`VITE_PKC_EMBED_URL=... pnpm build` exit 0。

## 边界

- 这是**超时启发式**，不是服务器 401/403 状态码解析；真实 SSO/403 仍待 PKC 属主接入。
- 不声明生产可用；不声明 F-036 可关闭。
